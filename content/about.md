## Publications

- **BluTrain: A C++/CUDA Framework for AI Systems**
  [arXiv:2606.24780](https://arxiv.org/abs/2606.24780)
  *A robust, lightweight, and architecture-general training framework built from first principles in standard C++ and the core CUDA programming model. Every layer is implemented natively: a typed tensor module with reverse-mode autograd, a linear-algebra library, a caching allocator, a multi-mode distributed-execution module, and an MLIR-based deep-learning compiler. In formal evaluations training a 124M-parameter GPT-2 in FP32 on an 8-GPU RTX 6000 Ada system, BluTrain outperforms PyTorch in throughput (407K tokens/s vs 395K tokens/s) and memory efficiency (up to 22% footprint reduction), while strictly preserving numerical fidelity.*
